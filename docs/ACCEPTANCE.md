# Preview evidence

The TypeScript, AUI and Windows Go development builds completed locally. Desktop/mobile screens were rendered in Chrome against isolated NTFS data. My Maps renders real OpenStreetMap tiles. My Meet connects to its embedded LiveKit engine; two synthetic standalone identities joined through host approval and displayed live media tiles and shared meeting chat.

No physical camera/microphone quality, Internet NAT traversal, 32-person capacity, clean Windows host, exhaustive feature/security audit or full Google parity claim is made. See README for precise capabilities and remaining gaps. Release and installed-runtime receipts are recorded separately when completed.
